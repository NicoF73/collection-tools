Lege in GitHub unter Settings, Developer settings ein „Fine-grained personal access token“ an: nur für dieses eine Repository, Berechtigung „Contents: Read and write“, mit Ablaufdatum. Nutze ein privates Repository für die Daten, denn in einem öffentlichen wären sie für alle lesbar. Importiert werden die .xml-Dateien des Ordners, exportierte Chats landen als .md im selben Ordner. Ohne Merken gilt das Token nur für diesen Tab.
